Update Ticker Assumptions

Edit the valuation growth rate and projected profit margin for one ticker. Submission triggers a GitHub Actions workflow that updates the DB, opens an audit issue (emails repo owner), and queues a site refresh.

 
GitHub token (one-time setup)

Submitting calls the GitHub REST API directly. You need a fine-grained personal access token scoped to the ndaly111/StockFinances repo with Actions: read & write permission. Generate one at github.com/settings/tokens?type=beta. The token is stored only in this browser's localStorage; nothing leaves your machine except the dispatch call to GitHub.

No token saved

After submit: wait ~25 minutes for the site to refresh, then hard-refresh (Ctrl+F5) the ticker's page to see the new valuation chart. You'll also get an email from GitHub when the audit issue is opened.
